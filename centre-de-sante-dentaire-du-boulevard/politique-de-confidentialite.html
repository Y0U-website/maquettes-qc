Pendant combien de temps vos données sont-elles conservées ?

Pour les utilisateurs qui s’enregistrent sur notre site (si cela est possible), nous conservons également les données personnelles indiquées dans leur profil. Tous les utilisateurs peuvent voir, modifier ou supprimer leurs informations personnelles à tout moment (à l’exception de leur nom d’utilisateur). Les gestionnaires du site peuvent aussi voir et modifier ces informations.

Pour toutes les données médicales qui transitent à travers le site web, nous les conservons pendant 5 années.

Quels sont vos droits sur vos données ?

Vous pouvez demander à recevoir un fichier contenant toutes les données personnelles que nous possédons à votre sujet, incluant celles que vous nous avez fournies. Vous pouvez également demander la suppression des données personnelles vous concernant. Ceci ne prend pas en compte les données conservées à des fins administratives, légales,médicales ou pour des raisons de sécurité.
